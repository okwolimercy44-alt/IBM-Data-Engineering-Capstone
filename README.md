# IBM-Data-Engineering-Capstone
Practical data engineering exercises covering database design, SQL, data ingestion, ETL pipelines, data processing, automation and analytics.

## Objectives
To develop practical experience with:
  
  1. Relational database design and administration
  2. SQL and data manipulation
  3. Data ingestion and extraction
  4. Data pipelines and ETL
  5. Data processing and transformation
  6. Automation and scripting
  7. Analytical data workflows

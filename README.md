# IBM Data Engineering Capstone

A hands-on data engineering project focused on building practical skills in database design, SQL, data ingestion, data extraction, automation, and analytical data workflows.

## Project Objectives

To develop practical experience with:

1. **Relational Database Design and Administration** – Creating databases, designing tables, and managing database structures.
2. **SQL and Data Manipulation** – Writing SQL queries to create, retrieve, and manage data.
3. **Data Ingestion** – Importing structured datasets into relational databases.
4. **Data Extraction** – Exporting database tables and their contents into SQL files.
5. **Database Optimization** – Creating and managing indexes to improve data retrieval.
6. **Automation and Scripting** – Using Bash scripts and Docker commands to automate database operations.
7. **ETL and Data Pipelines** – Understanding and implementing processes for extracting, transforming, and loading data.
8. **Data Processing and Transformation** – Preparing and transforming data for downstream use.
9. **Analytical Data Workflows** – Building foundations for data analysis and reporting.

## Technologies and Tools

- **MySQL** – Relational database management.
- **Docker** – Running database services in containers.
- **DBeaver** – Database connection, administration, and SQL execution.
- **Git and GitHub** – Version control and project documentation.
- **Git Bash** – Executing Bash scripts and command-line operations.

## Project Progress

- Created a MySQL database named `sales`.
- Created the `sales_data` table.
- Imported 2,604 records from a CSV dataset.
- Created and verified an index on the `timestamp` column.
- Developed and executed a Bash script to export the table into an SQL file.
- Documented SQL operations, commands, and results.
